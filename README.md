# 1 Month Anniversary Page

Open `index.html` in a browser. Nothing to install.

## Edit these
- `js/main.js`, the CONFIG block at the top: names, start date, week notes, photo captions, coupons, and the letter.
- `images/`: replace or add photos, then update the `photos` list in CONFIG.
- `audio/song.mp3`: optional. Put your song here and it plays instead of the built-in melody.
- Extras in `main.js` (bottom): `CONFIG.chapters` (big photo scenes) and `CONFIG.reasons` (the 12 flip cards).

## Share it
Zip the whole folder and upload it to Netlify Drop (drop.netlify.com) or GitHub Pages. You get a link to send her.
You can also override names and date in the link: `index.html?her=Ruthba&me=Tashkir&start=2026-09-28T00:00:00`
